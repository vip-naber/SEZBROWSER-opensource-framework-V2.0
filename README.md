# 🌐 SezBrowser v1.0 - Open Source Web Browser

Acrox Systems Labs tarafından geliştirilen, tamamen açık kaynaklı, hafif ve Chromium tabanlı güvenli web tarayıcısı iskeleti. Python ve PyQt5 mimarisi kullanılarak maksimum performans odaklı tasarlanmıştır.

## 🚀 Özellikler
* **Chromium Çekirdeği:** Modern web siteleriyle tam uyumlu, hızlı sayfa yükleme motoru.
* **Minimalist Siber Arayüz:** Gereksiz eklentilerden arındırılmış, RAM dostu arayüz.
* **Tamamen Özgür:** Reklam engelleyici (AdBlock) veya kendi VPN protokollerinizi enjekte edebileceğiniz esnek kod yapısı.
* **u-block origin lite yüklü gelir.
* **tor sekme modu ve gizli pencere vardır
## 🛠️ Kurulum ve Çalıştırma Kılavuzu

SezBrowser'ı bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyin:

1. Bilgisayarınızda **Python 3.x** kurulu olduğundan emin olun.
2. Bu depodaki dosyaları indirin ve terminal/komut satırını bu klasörde açın.
3. Gerekli kütüphaneleri yüklemek için şu komutu çalıştırın:
   ```bash
   pip install -r requirements.txt
Tarayıcıyı ateşlemek için ana kodu çalıştırın:

Bash
python browser.py
